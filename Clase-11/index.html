Modo oscuro con localStorage

Tocá el switch de arriba a la derecha para cambiar entre modo claro y oscuro. La preferencia queda guardada en el navegador: recargá la página o cerrala y volvé a abrirla — el tema se mantiene. ✨

¿Cómo funciona?

  1. El tema actual se guarda en el atributo data-tema del <html>.
  2. El CSS pinta los colores según ese atributo usando variables.
  3. Al tocar el switch, JavaScript guarda la elección en localStorage.
  4. Al cargar la página, se lee localStorage y se aplica el tema guardado.
