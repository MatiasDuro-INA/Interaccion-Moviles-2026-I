ARIA: atributos más usados

1. aria-label

Le da una etiqueta textual a un elemento que no tiene texto visible. Típico caso: botones que solo tienen un ícono.

<button aria-label="Cerrar diálogo">✕</button>

2. aria-labelledby

Igual que aria-label, pero apunta al id de otro elemento que ya tiene el texto. Útil para no duplicar texto.

<section aria-labelledby="titulo">
  <h2 id="titulo">Mi sección</h2>
</section>

3. aria-describedby

Apunta al id de un elemento que describe a este. Típico para ayudas de formularios o mensajes de error.

Mínimo 8 caracteres, incluí un número.

4. aria-hidden

aria-hidden="true" oculta el elemento del árbol de accesibilidad (los lectores de pantalla lo ignoran), pero sigue siendo visible para los ojos.

5. aria-expanded

Indica si un elemento expansible está abierto o cerrado. Imprescindible para menús, accordions, dropdowns.
